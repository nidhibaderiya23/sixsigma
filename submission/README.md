# ERGent: submission folder

Everything for the Cornell Six Sigma Hackathon submission (Devpost, due Sat Oct 17, 1 PM ET).

| File | What it is |
|---|---|
| [`submission-checklist.md`](submission-checklist.md) | Review, push, deploy and Devpost steps, and how the repo meets each judging criterion |
| [`devpost.md`](devpost.md) | Every Devpost field, ready to paste |
| [`screenshots/`](screenshots/) | Seven images for the Devpost gallery, numbered in upload order |
| [`demo-video-script.md`](demo-video-script.md) | An optional 2.5-minute demo video script |

**The app:** the final version (v4, "Civic Ithaca") is on `main`. Earlier versions are kept on their
own branches and tags (`v1` to `v7`); see [`../VERSIONS.md`](../VERSIONS.md).

**The rest of the repo that judges look at:** [`../README.md`](../README.md),
[`../app/README.md`](../app/README.md) (every function), [`../data/README.md`](../data/README.md)
(codebook), [`../demo/README.md`](../demo/README.md) (the demo, number by number) and
[`../docs/six_sigma.md`](../docs/six_sigma.md) (Define and Measure).
