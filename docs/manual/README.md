# ERGent User Manual

This folder holds the ERGent User Manual, written for Team ERG's professor and class. It has six chapters in plain Markdown: [`00-about-us.md`](00-about-us.md) (a template for the creators to fill in), [`01-getting-started.md`](01-getting-started.md), [`02-dispatcher-guide.md`](02-dispatcher-guide.md), [`03-supervisor-guide.md`](03-supervisor-guide.md), [`04-statistics-explained.md`](04-statistics-explained.md) and [`05-glossary-faq.md`](05-glossary-faq.md). The script [`build_manual.py`](build_manual.py) joins them into one styled file with a cover page and a table of contents, [`ERGent-Manual.html`](ERGent-Manual.html), and then prints it to [`ERGent-Manual.pdf`](ERGent-Manual.pdf) with headless Google Chrome. To rebuild after editing any chapter, run `.venv/bin/python docs/manual/build_manual.py` from the repo root. The script uses the `markdown` package if it is installed (`pip install markdown`) and a small built-in converter if not, so it needs nothing else. It looks for Chrome at `/Applications/Google Chrome.app`; without Chrome it still writes the HTML, and you can use Print, then Save as PDF. The statistics chapter follows `app/qc.py`, so update it if the formulas there change. It also copies the HTML to `app/www/manual.html`, which the app serves at `/manual.html` (the **Manual** link in the header).
